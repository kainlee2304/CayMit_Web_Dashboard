# Frontend Module - TammySmartFruit Web Dashboard

Mô-đun giao diện người dùng xây dựng bằng **Next.js 16 (Turbopack, React 19, TypeScript, TailwindCSS)**.

### Tính năng chính:
- **Dashboard Tổng quan:** Chẩn đoán AI kéo thả ảnh, xem chỉ số vi khí hậu và cảnh báo dịch bệnh.
- **Camera Live & Snapshot:** Giám sát vườn trực tiếp và nhận thông báo chụp tự động.
- **Quản lý Lô & Truy xuất Nguồn gốc:** Tạo mã lô, in tem QR, theo dõi dòng thời gian khối liên kết SHA-256.
- **Thống kê Báo cáo:** Biểu đồ xu hướng dịch bệnh và chất lượng quả thu hoạch qua Recharts.
- **Phân quyền & Phê duyệt:** Trang quản trị tài khoản đa vai trò (`admin`, `producer`, `processor`, `logistics`).

### Hướng dẫn khởi chạy:
```bash
npm install
npm run dev
```
Truy cập: [http://localhost:3000](http://localhost:3000)
